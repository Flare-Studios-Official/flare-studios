## ✦ Core Experience Features

1. **Preloader Sequence**
   - Pure black genesis, glowing electric orange core, expanding luminous ring, masked wordmark reveal, and minimal progress counter.

2. **Full-Screen Cinematic Hero**
   - Interactive Canvas2D/WebGL ambient orb responding to cursor physics.
   - Massive typographic reveal: **WE MAKE IDEAS IGNITE.**
   - Magnetic call-to-action buttons with procedural interaction audio.

3. **Apple-Inspired Liquid Glass UI**
   - High-fidelity frosted glassmorphism (`backdrop-blur-xl`, `saturate-180%`).
   - Dynamic specular cursor reflections and glowing ambient light rims.

4. **Infinite Studio Marquee**
   - Dual-row alternating kinetic typography with speed and color reaction on hover.

5. **Featured Work (Selected Demonstration Concepts)**
   - `01 — VELOCITY` (Motion Graphics)
   - `02 — NEXUS` (Brand Identity)
   - `03 — AFTERGLOW` (Video Editing)
   - `04 — PIXEL RUSH` (Thumbnail Design)

   - `06 — FREQUENCY` (Promotional Design)
   - Interactive 3D tilt cards, custom procedural artworks, and full-screen case study modal breakdowns.

6. **Interactive Services with Procedural Visualizers**
   - Video Editing, Motion Graphics, Thumbnail Design, Graphic Design, and Web Design & Development.

## ✦ Tech Stack

- **Runtime & Build**: Node.js, Vite 8, TypeScript
- **Styling**: Tailwind CSS 3.4, Apple Liquid Glass utilities, CSS custom properties
- **Animation**: Framer Motion, Canvas2D procedural shaders, requestAnimationFrame lerp physics
- **Icons**: Lucide React
- **Sound**: Web Audio API Sound Engine (zero external audio file dependency)
- **Effects**: canvas-confetti

## ✦ Local Development

```bash
# Clone the repository
git clone https://github.com/Flare-Studios-Official/flare-studios.git

# Navigate into project directory
cd flare-studios

# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build
```
